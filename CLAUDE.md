# Start here (Claude sessions)

This GitHub repo is NOT where Host Mode's work happens. It only holds two small helper agents (see README.md) and the
redirect pages for old hostmode.github.io links.

The code, the rules and the notes live on GitLab: host-mode-group/hostmode (branch main). Before doing anything:

1. Clone it with the GitLab access this cloud environment provides (the GITLAB_TOKEN variable), for example
   `git clone https://oauth2:$GITLAB_TOKEN@gitlab.com/host-mode-group/hostmode.git`.
2. Read, in this order: CLAUDE.md, PLAYBOOK.md (its "Waiting on Roy" list is the current to-do list) and the top of
   CHANGELOG.md.
3. Work there: branches and merge requests on GitLab, merged only with Roy's OK. Never push the site's code to GitHub.
