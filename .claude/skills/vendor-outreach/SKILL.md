# Vendor outreach

Help vendors see why the vendor page makes their event day easier. No account, no app to download.

## What the vendor page does (live today)

- One private link per vendor per event.
- Arrival time with an "I'm here" button, so the planner sees who has arrived.
- The live run of show with their moments highlighted, and a heads-up before each one.
- When the schedule shifts ("running late"), their phone shows the new times.
- Planner notes and a button to flag a problem.
- Extra details by vendor type (caterers: headcount and meal times; DJs: music cues; photographers: shot list; florists and rentals: delivery and pickup).

## Ask first

- Who: vendor name, type, and whether a planner using Host Mode introduced them.
- Channel: email, text or DM. First message or follow-up.

## Write

- Short: email 80 to 120 words, text 2 to 3 sentences.
- Open with their day: "No more scrolling a group chat for the timeline."
- One proof point that fits their trade. One easy ask: "Your planner will send your link; tap it on the day."
- If written for a planner to send, write it in the planner's voice and name.
- Spanish version on request.

## Rules

- Never name other apps. Never promise features that aren't live.
- The vendor page shows only their event's details; reassure them their info stays private.
- Remind the sender to log it in Sales if it's Host Mode's own outreach.

## Host Mode rules that always apply

- Plain, friendly words written for planners and hosts. No technical jargon.
- Never name a competitor or another app in anything public. Say "other apps". Unfinished features are "coming soon".
- Host Mode only tracks money. It never takes or sends payments.
- Never put customer data in the repo (it is public). Use the demos for examples.
