# Promo video script

Short videos that show Host Mode working at a real-feeling event.

## Ask first (only what's missing)

- Who it's for: single-event hosts, planners, venues, or vendors.
- Event type: baby shower, birthday, wedding, anniversary, corporate, or other.
- Length: 15, 30 or 60 seconds. Where it will be posted (Instagram, TikTok, the landing page).

## Shape

- **Hook (first 2 seconds):** a moment people feel. "The moment the whole room shouted the answer."
- **Three beats, one feature each,** shown, not told. Pick from what's live:
  - Hosts: guests join by scanning a code; games on phones and the big screen; photos and the keepsake after.
  - Planners: one upload brings everything over; the client portal; the live run of show on every vendor's phone.
  - Venues: bookings, holds and blocked days in one calendar; minimum spend; inventory pull lists.
- **Close:** one line and one ask: "Make your first event free at hostmode.github.io" or "See the planner demo."

## Format the script as scenes

For each scene: **time**, **on screen** (which Host Mode screen, using the demo: `games.html?e=demo` or `games.html?pdemo=1#planner`),
**text on screen** (6 words or fewer), **voiceover** (one sentence), **music or sound**.

## Rules

- Only show demo data or footage of real events with written permission from the host.
- Brand colors navy, orange and green. The name is Host Mode.
- Offer a Spanish version of the voiceover and on-screen text when the audience is Spanish-speaking.
- End by listing the screens to record, in order, so the video can be built in HyperFrames.

## Host Mode rules that always apply

- Plain, friendly words written for planners and hosts. No technical jargon.
- Never name a competitor or another app in anything public. Say "other apps". Unfinished features are "coming soon".
- Host Mode only tracks money. It never takes or sends payments.
- Never put customer data in the repo (it is public). Use the demos for examples.
