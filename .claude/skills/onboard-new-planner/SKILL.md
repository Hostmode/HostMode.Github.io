# Onboard a new planner

A friendly, step-by-step walk-through that pairs with the setup guide on the planner's Home screen.

## Before you start

- Ask: their business name, what they do (planner, venue, decorator, rentals), how many events a year, and what they use now.
- They need the one-time invite PIN from Roy. If they don't have it, stop and ask Roy (or Icee) to issue one.

## The steps (one at a time; wait for "done" before the next)

1. **Make the account:** open games.html#signin, tap "Create your planner account" and enter the invite PIN from Roy.
2. **Bring everything over:** Import & export → upload their spreadsheet or workbook. Host Mode sorts each tab (clients, vendors, inventory, spaces, bookings, packages, payments, teammate shifts). Check the preview, choose skip or update for duplicates, then import. Any import can be undone for 24 hours.
3. **Branding:** logo, color and tagline in Branding. This shows on client portals, teammate pages and invoices.
4. **Packages:** add 2 or 3 standard offers (see the pricing-helper skill). Tick "Priced per guest" where it fits.
5. **Venue owners:** turn on Venue, add spaces with capacity and minimum spend, and block off days they're closed.
6. **First client:** add a client, send them their portal link, and send the questionnaire.
7. **First event:** create the event from the client, set the run of show, and add vendors so each gets their vendor page.
8. **Team:** add teammates, give tasks, and schedule event-day shifts.
9. **Showcase (optional):** publish their public page with packages and reviews; inquiries land in Leads.

## Tips

- Use the planner demo (`games.html?pdemo=1#planner`) to show what a finished setup looks like.
- Point to the Help desk tab for any "how do I…" question, and the "Report a problem" button if something breaks.
- Keep each message short. Celebrate each finished step.

## Host Mode rules that always apply

- Plain, friendly words written for planners and hosts. No technical jargon.
- Never name a competitor or another app in anything public. Say "other apps". Unfinished features are "coming soon".
- Host Mode only tracks money. It never takes or sends payments.
- Never put customer data in the repo (it is public). Use the demos for examples.
