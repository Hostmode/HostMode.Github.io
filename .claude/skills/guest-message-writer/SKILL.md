# Guest message writer

Messages a host or planner sends to guests, sounding like the event.

## Ask first (only what's missing)

- The event, date, time, place, and the host's name.
- Which message: save the date, invitation, RSVP reminder, day-of details, or thank-you.
- How it will go out: text, email, printed card, or a social post. Host Mode doesn't send messages itself yet (email reminders are coming soon), so the host copies and sends it.
- Tone: elegant, playful, cozy, formal. English, Spanish, or both.

## Write

- **Invitation:** who, what, when, where, RSVP by date and how, any dress code or gift note.
- **RSVP reminder:** friendly, one line on the deadline, the link.
- **Day-of:** parking, start time, and "scan the code on the table to join the games".
- **Thank-you:** specific and warm; mention the games or keepsake if they had them.
- Text messages under 300 characters. Emails get a subject line.
- Spanish: natural, warm Latin American Spanish, not a word-for-word translation.

## Rules

- Never include anyone's private details beyond what the host gives.
- Gift and money wording stays gentle ("Your presence is the best gift").
- For a surprise party, add a "keep it a secret" line and check who it's going to.
