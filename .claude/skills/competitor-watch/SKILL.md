# Competitor watch (staff only)

A monthly check of what other event apps charge and offer, so Host Mode stays ahead. Results go only into the staff-only competitor report and the Resources tab, never into anything public, the app's public screens, or this repo.

## Steps

1. Open the current competitor report (Roy or Icee shares it) and note the date of the last check.
2. For each app in the report, look up its public pricing page and recent feature announcements. Use web search; note the date you checked and the link.
3. Record changes only: new prices, new plans, new features, features removed, new apps worth watching (especially ones aimed at Charlotte-area planners and venues).
4. For each change, one line on what it means for Host Mode: "They added e-signatures; ours is on hold. Planners may ask."
5. Update "Where Host Mode wins" and "Gaps to close". Suggest at most three items for the To-Do List.

## Rules

- Facts with sources and dates. If a price isn't public, say "not listed".
- Never copy their wording, screenshots or designs.
- Competitor names stay in staff-only places. Because this repo is public, don't write findings into any file here.
- Paid tools stay on hold; note them for the future build plan.
